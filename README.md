📈 Investment Calculator
Author: Shelby Joiner
Course: CS 210 – Programming Languages, SNHU
Project: Final Project – Compound Interest Calculator
Language: C++

🚀 Overview
This project is a compound interest calculator designed to help users visualize their investment growth over time, both with and without monthly deposits. The calculator outputs formatted year-end reports based on user inputs, including:

Initial investment amount

Monthly deposit

Annual interest rate

Number of years to invest

It features two output reports:

Without Monthly Deposits

With Monthly Deposits

💡 Features
Calculates interest annually and monthly.

Provides clear, formatted output with year-end balances.

Uses object-oriented principles with a dedicated Investment class.

Demonstrates formatted console output using iomanip.

Includes functionality to handle compound interest and cumulative investment tracking.

🧩 Technical Implementation
Written in C++

Main logic encapsulated in the Investment class

Utilizes:

iostream for user interaction

iomanip for formatting output

cmath for calculations

📋 Project Management: Scrum Framework
This project was developed using the Scrum Agile methodology, following iterative sprints, sprint planning, daily standups, reviews, and retrospectives. Key tools used included:

Jira: Task tracking and backlog grooming

Slack & Zoom: Team communication and sprint ceremonies

Confluence: Documentation

The Scrum framework enabled adaptability to changing requirements (e.g., user interface feedback and new feature additions) and continuous improvement through retrospectives.
